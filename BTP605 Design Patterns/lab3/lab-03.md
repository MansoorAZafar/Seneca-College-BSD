# Lab 3

In this lab you will create a new design for a framework to create data structure animations like those found here:

https://cathyatseneca.github.io/DSAnim/



## Specs and Requirements:

* Animations are to be built using p5.js
  * all p5.js sketches has 2 functions, setup() called exactly one time at start
  * draw() function, which generally will be called 60times each second.  Typically you would loop through all your objects, update their states and draw them.

* The animations include various visual representations of the data. (for example arrays can be represented as just numeric values or as bars)

* As the animations are suppose to match an algorithm or a data structure, it is important to be able to create the algorithm in terms of the algorithm, i.e., if we want to create a bubble sort animation, the algorithm to generate the animation should be related to the bubble sort algorithm

* various controls are needed:
  * ability to "play" the animation
  * ability to change speeds
  * ability to "add" values
  * ability to "reset" the animation
  * and more...

## Submission and Requirements

* Work in a team of 2 or 3 but each person must submit their own copy of presentation material.  Be sure to include the names of your teammates in your submission.

* Design a solution and stub out the various classes (you don't need working code, just classes/function declaration, possibly with some print statements)
* Be ready to present the solution in week 7 lab class (no more than 5 min per group)
