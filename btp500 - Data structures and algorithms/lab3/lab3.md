# Lab 3 Reflection

  In this lab I learnt how to implement a doubly linked list in python with and without the use of sentinel nodes. I aslo got a better understanding on how to manage both the previous and next nodes of a doubly linked list; more specicially, how to push and pop out of both sides. I also got to learn how to implement Sentinel Nodes wihtout the use of a seperate class, rather just their concepts without making an external class for them. Overall though, I prefer working without Sentinel-Nodes but rather just a pointer to the head and tail that also acts as the head. So it is a points to the head and tail respectively and stores the value of the head and tail as-well. This way, you get to add more value rather than just having a 'sign post', you have the actual node and you keep track of it.
